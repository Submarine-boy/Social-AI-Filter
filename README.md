# Social AI Filter

AI-powered communication intelligence platform for helping creators and businesses prioritize important social-media messages, opportunities, and relevant conversations.

## Planned stack
- Frontend: HTML, CSS, JavaScript
- Frontend hosting: Vercel
- Backend: Python + FastAPI
- Backend hosting: Render
- Database and authentication: Supabase
- AI analysis: Groq

Development and testing will be cloud-first through GitHub deployments rather than local servers.
